## Findings
| ID | Severity | Evidence and impact | Required action |
|---|---|---|---|
| AUD-01 | High | app/main.py exposes document deletion, memory and model routes without authentication/tenant authorization. | Add verified identity, permissions and tenant filtering before real data or network exposure. |
| AUD-02 | High | TraceLogger.write serializes complete records directly; no claimant-name/claim-number redaction boundary. | Redact before every trace/audit sink; test nested payloads, errors, and raw model output. |
| AUD-03 | High | /course mounts the entire course directory, including results and fixture data. | Serve a dedicated public asset allowlist; keep traces, datasets and results outside it. |
| AUD-04 | High | Agent wall-clock/token/cost checks run between loop steps; final generation can run after a budget threshold, and provider calls have their own longer timeout. | Enforce an absolute deadline across decision, tools, compression and finalization; define token/cost overshoot policy. |
| AUD-05 | High | Chroma collections and session memory have no authenticated tenant boundary. | Make access context mandatory for ingestion/search/source lookup/memory; reject missing scope. |
| AUD-06 | Medium | main.py mixes routes, upload orchestration, trace assembly and local UI serving. Services use concrete provider/store objects through one builder. | Extract feature routers/use cases and narrow ports, preserving contracts. |
| AUD-07 | Medium | MCP pseudo-source citations use /sources IDs absent from the Chroma lookup. | Introduce a typed evidence resolver; retain provenance and access checks for tool/resource evidence. |
| AUD-08 | Medium | MCP registry imports shared tool types from an HR implementation; tool schema/catalogue concerns cross domain boundaries. | Move shared observations/failures/interfaces into domain/application contracts. |
| AUD-09 | Medium | Synchronous local Chroma plus in-process locks/caches assumes a single process; uploads are handled within HTTP requests. | Retain single-process mode until measured need; design durable ingestion jobs and shared stores before scaling workers. |
| AUD-10 | Medium | Historical links reference missing Week 6/7 guides/scenarios; backups contain unique historical documents. | Inventory callers and historical evidence before deleting or relocating. |
| AUD-11 | Medium | Earlier evaluations are predominantly HR; supplied Task D requirements require real adjuster questions, claims traces and blind human labels. | Reuse mechanisms, collect new authorized domain evidence; do not relabel HR results. |
| AUD-12 | Low | Root folders mix application, course scripts, evidence, generated HTML and handoff documentation. | Migrate in tested stages using the roadmap, not a bulk move. |

No runtime fixes are claimed in this initial pass. High findings block production release; the local fictional coursework remains the current supported scope.
